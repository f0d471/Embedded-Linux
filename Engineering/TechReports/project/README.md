# project 系列

`Project/` 是这个学习仓的整合项目：在 100ASK_IMX6ULL Pro 开发板上逐层长出一台
可运行、可复测的设备。每完成一个工作点就多出一块能力，各占一章。

本系列记录这棵代码树自身的开发过程。一层从空壳变成有实现、构建系统换法、
判据体系变化，各算一个工作点。

| 章 | 工作点 | 状态 |
|---|---|---|
| [01](01-先立骨架-分层启停与两棵产物树.md) | 骨架：六层空壳、启停顺序、两棵产物树、18 条判据 | 本机验讫，未上板 |
| [02](02-日志落文件-让现有LOG自动写入文件.md) | 日志落文件：`log_redirect`、`O_APPEND`、系统 errno、判据增至 29 条 | 本机验讫，未上板 |
| [03](03-display层-两个后端与一张能数的图.md) | display 层：注册链表、真假两个后端、画点填矩形、单测与独立计数、判据增至 52 条 | 本机与板上均验讫（板上那一组没接显示器） |
| [04](04-font层-从UTF-8到帧缓冲灰度合成.md) | font 层：严格 UTF-8、builtin/FreeType、baseline/advance、alpha/pitch/裁剪，判据增至 65 条 | 本机、ARM 与真 framebuffer 均验讫 |

| [06](06-netinput-第二个输入源走网络.md) | netinput：20 字节线上格式、get_fds 契约、坏客户端隔离，判据增至 83 条 | 本机与板上 loopback 均验讫 |
| [07](07-多线程-环形队列与读取线程.md) | 读取线程与环形队列：丢最旧、三本账、cond 绑单调时钟，判据增至 90 条 | 本机验讫（压力对账 + tsan） |
| [08](08-GUI四层-config-ui-page-business.md) | config/ui/page/business 四层：按钮、页面切换、命令执行、端到端回放链，判据增至 124 条 | 本机与板上均验讫（板上 GUI 真写 fb） |
| [09](09-测试项-I2C光感与串口.md) | items 测试项：i2c-dev 直读 AP3216C、termios 帧回显、伪终端对端 | 本机与板上均验讫；板上抓到并修复探测缺陷 |
