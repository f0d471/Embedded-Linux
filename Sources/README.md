# sources：原始资料库（不入 git）

仓库四部分之一。这里放知识的**源头材料**：原书 PDF、视频字幕、厂商手册、外部源项目。
内容一律不入库（规则见 `.gitignore`），本 README 是唯一入库的文件，充当整座库的
资料地图：每份资料是什么、在哪、本仓哪里消化了它。

仓库定位是"教程完全自足"：Knowledge/ 里的教程把这些资料的知识**提取完**，
读者不需要再去看视频、翻原书。原始资料只服务两件事——教程改写时的素材来源，
以及教程没覆盖到时的最终兜底。
