# project 系列

`project/` 是这个学习仓的终点整合项目：在 100ASK_IMX6ULL Pro 开发板上做一台
网络视频终端。它一层一层长出来，每完成一个工作点就多出一块可运行、可复测的能力。

本系列记录这棵代码树自身的开发过程。一层从空壳变成有实现、构建系统换法、
判据体系变化，各算一个工作点，各占一章。

| 章 | 工作点 | 状态 |
|---|---|---|
| [01](01-先立骨架-分层启停与两棵产物树.md) | 骨架：六层空壳、启停顺序、两棵产物树、18 条判据 | 本机验讫，未上板 |
| [02](02-日志落文件-让现有LOG自动写入文件.md) | 日志落文件：`log_redirect`、`O_APPEND`、系统 errno、判据增至 29 条 | 本机验讫，未上板 |
| [03](03-display层-两个后端与一张能数的图.md) | display 层：注册链表、真假两个后端、画点填矩形、单测与独立计数、判据增至 52 条 | 本机与板上均验讫（板上那一组没接显示器） |
| [04](04-font层-从UTF-8到帧缓冲灰度合成.md) | font 层：严格 UTF-8、builtin/FreeType、baseline/advance、alpha/pitch/裁剪，判据增至 65 条 | 本机、ARM 与真 framebuffer 均验讫 |
| [05](05-input层-把evdev原始帧变成应用事件.md) | input 层：replay/evdev、SYN 帧、丢帧恢复、相对/绝对坐标、按键与超时，判据增至 73 条 | 本机与 ARM 回放验讫；板上真实 evdev 探测/超时验讫，未接 USB 鼠标 |

层的实现进度与当前终点见 [`../../Todo/项目路线图-网络视频终端.md`](../../Todo/项目路线图-网络视频终端.md)。
第 04/05 章的章末架构图在 [fig/](fig/)，按 Efinix 仓的配图规范绘制
（白底、线型承载"是否已接入"、灰虚线为未接入的下游）。
每章的代码逐行讲解见 [`../../CodeReading/project/`](../../CodeReading/project/)，
判据数字的出处是各章第五节。
