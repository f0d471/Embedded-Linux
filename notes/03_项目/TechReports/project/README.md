# project 系列

`project/` 是这个学习仓的终点整合项目：在 100ASK_IMX6ULL Pro 开发板上跑一个
带图形界面的电子产品量产工具。它一层一层长出来，每学完一个层级就多出一层实现。

本系列记录这棵代码树自身的开发过程。一层从空壳变成有实现、构建系统换法、
判据体系变化，各算一个工作点，各占一章。

| 章 | 工作点 | 状态 |
|---|---|---|
| [01](01-先立骨架-分层启停与两棵产物树.md) | 骨架：六层空壳、启停顺序、两棵产物树、18 条判据 | 本机验讫，未上板 |
| [02](02-日志落文件-用dup2换掉2号槽.md) | 日志落文件：`log_redirect`、`O_APPEND`、判据增至 26 条 | 本机验讫，未上板 |
