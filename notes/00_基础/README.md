# 00 基础通用知识

## 这个文件夹解决什么问题

主线章节（01、02、03...）讲的是"这一章的事"，遇到通用名词只能一笔带过，
不然主线就断了。但一笔带过的结果是：你看到 `s0`、`sysroot`、`PLT` 这种词，
知道它在句子里的位置，却不知道它是什么。

所以约定：

    主线章节里出现一个名词，如果它
        不属于本章主线            例如 ARM 寄存器编号不属于"工具链"这一章
        且以后还会反复出现        例如 ELF、系统调用、动态库
    就在这里单开一篇，主线里只留一句话加一个跳转。

用到就加，不预先写全。没被任何一章引用过的篇章不要写。

## 体例

每篇都按同一个结构：

    1. 一句话说它是什么
    2. 和你已知的东西对照 —— 这一节必须有。
       你有 ysyx（RISC-V）和数字 IC 基础，所以每个概念都从 RISC-V 那边搭桥过来，
       只讲"ARM/Linux 这边不一样在哪"，不从零讲什么是寄存器。
    3. 展开讲，配 ASCII 图
    4. 怎么亲手验证（命令 + 每个参数在干什么）
    5. 被哪些章节用到
